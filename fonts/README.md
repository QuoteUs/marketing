# Fonts

**Newsreader** (variable, roman + italic) by Production Type, SIL Open Font License 1.1 (`OFL.txt`).
Used for headlines and quotes. Install the `.ttf` files for design tools (Figma, Keynote, Canva); use the `.woff2` files on the web.

The sans-serif is the system stack (SF Pro / system-ui), which is not redistributable and not included.
